# Customer Satisfaction & Net Promoter Score (NPS) Analysis

## 📌 Project Overview

This project analyzes customer survey responses to measure customer loyalty and satisfaction using the Net Promoter Score (NPS) framework.

The survey dataset contains customer ratings ranging from **0 to 10**, where respondents are classified as:

* **Promoters:** Ratings 9-10
* **Passives:** Ratings 7-8
* **Detractors:** Ratings 0-6

The project was developed using **Python, NumPy, Pandas, Matplotlib, and Google Colab**.

---

## 🎯 Objective

The objective of this project is to:

* Analyze customer feedback data.
* Calculate Net Promoter Score (NPS).
* Segment customers into Promoters, Passives, and Detractors.
* Visualize customer sentiment using charts.
* Generate business insights from survey responses.

---

## 📈 Methodology

### 1. Load Dataset

The survey data is loaded using NumPy.

### 2. Identify Customer Segments

Customers are categorized according to the NPS methodology:

| Rating | Category  |
| ------ | --------- |
| 9-10   | Promoter  |
| 7-8    | Passive   |
| 0-6    | Detractor |

### 3. Calculate NPS

NPS is calculated using:

NPS = (% Promoters) - (% Detractors)
